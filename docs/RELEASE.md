# 0.3.1 开源准备

## 发布内容

独立的 DeepSeek Harness 自然对话插件，包含人格配置、对话规划、独立回复生成、可追溯记忆、表达学习与设置页面。项目采用 GPL-3.0-only，来源归属见 [设计参考](../THIRD_PARTY_NOTICES.md)。

本次重写默认角色文案，并补充旧默认值迁移、原子保存、配置版本冲突检测、记忆操作保留设置草稿、范围切换隔离、晚到请求取消及进程锁恢复。

## 安装和验证

项目仓库：https://github.com/aki66938/dsh-natural-dialogue 。不要上传本机运行数据或归档目录中的运行备份。首次开源建议先在独立工作区验证。

从源码安装与检查：

```powershell
npm ci --ignore-scripts
npm test
npm run check
npm run format:check
dsh plugin --profile desktop add "<本项目绝对路径>"
```

重启 DSH 后在设置中打开「自然对话」。该插件会增加模型调用、费用和回复延迟，近期文本会发送给用户配置的模型服务；可选嵌入服务也会接收查询及记忆文本。具体开关、数据位置和删除范围见 [README](../README.md)。

## 已知限制

- 风格受基础模型、历史对话和任务内容影响，不能保证每轮都保持相同口吻。
- 回复改写具有事实校验与回退，但无法保证全部语义无损；重要结果仍需核对。
- 尚无多模态记忆、跨回合事件重建、向量批量回填与复杂图推理。
- 同库只允许一个写入进程，多 profile 默认不自动隔离；损坏锁保守拒绝写入。
- 当前验证以 Windows 本机为主，没有完整跨平台桌面验收或长期记忆质量评估。

完整边界见 [架构说明](ARCHITECTURE.md)。本地归档代表归档时的源码快照；仓库提交、CI 结果与发布版本以 GitHub 记录为准。
